To activate the optional Food Inflation visualizations:

1) Open https://www.worldbank.org/en/brief/2025/05/04/inflation-database
2) Click "Inflation data (Excel)".
3) Save the official downloaded file as Inflation-data.xlsx in this directory.
4) Restart Streamlit or use the uploader in the GDP & Inflation tab.

The workbook needs a sheet named fcpi_a (annual FOOD CPI inflation percentages),
with Country Code and 2017..2025 year columns. hcpi_a is optional.

There is intentionally no simulated inflation data in this project.
